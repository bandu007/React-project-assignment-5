# React Custom useFetch Hook

## Project Overview
A React application demonstrating a custom `useFetch` hook that fetches data from an API and manages loading and error states.

## Features
- Fetches data from a REST API
- Displays a loading indicator while data is being fetched
- Handles network errors gracefully
- Uses a reusable custom React hook

## Technologies Used
- React
- JavaScript (ES6+)
- Vite
- Fetch API

## Installation
- Clone the repository
- Run `npm install`
- Run `npm run dev`

## Build
Run `npm run build`
